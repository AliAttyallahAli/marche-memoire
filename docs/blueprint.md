# **App Name**: TokenFlow MLM

## Core Features:

- User Registration: User Registration and KYC: Secure user registration process with strong KYC (Know Your Customer) verification.
- Referral Tracking: Referral System: Track user referrals to attribute token generation to the correct upline.
- Purchase Verification: Product Purchase Verification: Verify product purchases to initiate token generation for the user and their upline.
- Token Generation: Token Generation: Automatically generate tokens based on pre-defined rules upon successful purchase validation.
- Wallet Creation: Wallet Creation: Generate a unique wallet for each user to receive generated tokens, without any on-chain component.
- Transaction history: Transaction Monitoring: Display the record of each user, capturing each purchase and associated referral bonuses, token amount.

## Style Guidelines:

- Primary color: Soft Blue (#7AB8FA) to evoke trust and stability.
- Background color: Very light blue (#EBF4FA) to maintain a clean, trustworthy, and unobtrusive feel.
- Accent color: A slightly more saturated blue (#5793D8), shifted ~30 degrees toward cyan to complement the primary color.
- Body and headline font: 'Inter' (sans-serif) to convey a modern, objective, and neutral look. It is also suitable for both headlines and body text.
- Use clean and professional icons related to transactions, wallets, and user profiles.
- A clean and intuitive layout to showcase products, user profiles, and token wallets. Grid-based layout with clear hierarchy.
